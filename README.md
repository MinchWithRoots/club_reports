# Принцип работы

Система автоматизирует процесс формирования, расчёта и хранения отчётности, избавляя администратора от ручных вычислений и упрощая работу с историей данных.

### 1. Авторизация

Администратор авторизуется в системе и получает доступ к функционалу формирования отчётности.

### 2. Выбор клуба

После авторизации администратор выбирает из выпадающего списка клуб, для которого необходимо сформировать отчёт.

### 3. Заполнение отчёта

Администратор заполняет необходимые поля. Значения, которые требуют расчёта, **вычисляются системой автоматически по заданным формулам**.

Это позволяет:

* исключить ручные вычисления;
* снизить вероятность ошибок;
* ускорить процесс подготовки отчёта;
* обеспечить единообразие расчётов.

### 4. Сохранение

После заполнения отчёта администратор сохраняет данные.

Система автоматически добавляет сформированный отчёт в базу данных, сохраняя всю необходимую информацию для дальнейшей работы.

### 5. Экспорт отчёта

Сохранённый отчёт можно скачать для дальнейшего использования или передачи.

### 6. История изменений

Для каждого отчёта сохраняется история изменений.

Администратор может увидеть:

* **когда** были внесены изменения;
* **кто** их внёс;
* какие изменения были выполнены с отчётом.

Таким образом, система обеспечивает не только автоматизацию расчётов, но и **централизованное хранение отчётности с прозрачной историей изменений**.
